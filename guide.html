SYSTEM FILE 02

02컷｜세계관 훅

인류는 지구를 잃었다.

2459년, 초지능 AI ECLIPSE의 폭주로 전력과 통신망이 붕괴하고 전쟁과 기후 재앙이 시작되었습니다.

살아남은 인류는 거대한 이주선 ARK를 타고 새로운 행성 노바테라로 탈출했습니다.

그리고 60년 후—

인류는 다시 우주로 향합니다.

SYSTEM FILE 03

03컷｜플레이 시작

시작부터 평범하지 않습니다.

당신의 출신과 선택이

첫 장면을 결정합니다.

죄수 개척 프로그램의 생존자가 될 수도 있고, 노바테라의 시민으로 새로운 삶을 시작할 수도 있습니다.

누명을 쓴 정치범, 무명의 노동자, 몰락한 상류층, 야심 찬 상인, 위험한 용병, 떠돌이 탐험가까지.

SYSTEM FILE 04

04컷｜높은 자유도

정해진 직업도, 정답도 없습니다.

살아남는 방식은

플레이어가 직접 선택합니다.

행성을 탐험하고, 폐허에서 자원을 모으고, 가게를 열고, 우주선을 구입하고, 세력에 가입하거나 적대할 수 있습니다.

영웅이 되지 않아도 됩니다.

SYSTEM FILE 05

05컷｜실시간 상태 시스템

모든 행동에는 현재 상태가 반영됩니다.

선택은 단순한 대사가 아니라

실제 생존 조건이 됩니다.

체력과 정신력, 산소, 허기, 장비, 위치, 시간, 보유 자금과 세력 평판이 실시간으로 변화합니다.

방사능, 감염, 부상, 굶주림, 정신 오염처럼 환경에 따른 상태이상도 발생합니다.

SYSTEM FILE 06

06컷｜시간이 흐르는 세계

대화하는 동안에도

세계의 시간은 흐릅니다.

당신이 쉬는 동안에도

세계는 계속 살아 움직입니다.

짧은 행동은 수 분, 제작과 수리는 수 시간, 대규모 건설과 연구는 수일 이상 소요됩니다.

시간을 건너뛰면 세계가 정지하는 것이 아니라 NPC, 사업장, 거점, 사건이 자동으로 변화합니다.

SYSTEM FILE 07

07컷｜ASTER 동행 AI

혼자 시작하지만,

완전히 혼자는 아닙니다.

ASTER는 당신의 선택을 학습하고

점차 자신만의 성격을 만들어갑니다.

보급형 지원 AI 로봇 ASTER는 환경 분석, 독성 검사, 광물 탐지, 수리 절차 안내와 탐사 데이터 기록을 담당합니다.

하지만 채굴하고, 싸우고, 제작하고, 살아남는 일은 플레이어가 직접 수행해야 합니다.

SYSTEM FILE 08

08컷｜탐사 시스템

발견되지 않은 행성으로 향하십시오.

준비되지 않은 탐사는

모험이 아니라 조난이 됩니다.

사막, 빙하, 화산, 심해, 원시림, 폭풍지대, 수정으로 뒤덮인 행성과 암흑 속 미개척지까지.

행성마다 기후와 중력, 자원, 생태계, 위험이 다르며 탐사 장비와 보급품이 부족하면 이동할 수 없습니다.

SYSTEM FILE 09

09컷｜자원 채집과 위험

눈앞의 자원이

항상 안전한 것은 아닙니다.

발견하고, 분석하고,

살아서 가져오십시오.

광물, 결정체, 외계 식물, 생체 조직, 고대 유물 등 행성마다 서로 다른 자원을 채집할 수 있습니다.

성분이 확인되지 않은 식물이나 생물 자원을 접촉하면 중독, 감염, 환각, 기생 등 예측하지 못한 문제가 발생합니다.

SYSTEM FILE 10

10컷｜제작과 설계도

주운 폐품 하나도

새로운 기술이 될 수 있습니다.

생존 장비에서

외계 기술까지.

채집한 자원과 설계도를 이용해 도구, 의료품, 드론, 무기, 방어구, 건설 장비와 우주선 부품까지 제작할 수 있습니다.

유적 조사, 장비 분해, 거래, 퀘스트, 암시장을 통해 새로운 설계도를 획득하고 기술을 발전시키십시오.

SYSTEM FILE 11

11컷｜전투 시스템

싸움의 결과는

장비만으로 결정되지 않습니다.

살아남았다면

그것도 승리입니다.

무기 성능, 방어구, 부상, 환경, 거리, 지형, 적의 생태와 현재 상태가 전투에 반영됩니다.

야생 생명체, 몬스터, 해적, 범죄 조직, 기계 군단, 적대 문명과의 전투가 발생할 수 있습니다.

도망치거나, 협상하거나, 함정을 설치하는 것도 선택입니다.

SYSTEM FILE 12

12컷｜정신 오염 시스템

우주의 공포는

육체만 공격하지 않습니다.

외계 포자, 고대 유물, 극도의 고립과 굶주림, 과도한 신체 개조는 정신 오염도를 상승시킵니다.

오염이 심해지면 환각과 환청이 발생하고, 상태창이 왜곡되며 통제력을 잃을 수도 있습니다.

안전한 거점, 치료, 약물, 휴식과 교감을 통해 정신을 회복해야 합니다.

SYSTEM FILE 13

13컷｜우주선 획득과 운용

우주선은 지급되지 않습니다.

한 척의 낡은 셔틀에서

거대한 함대까지.

구매하거나, 제작하거나, 버려진 함선을 수리하거나, 적의 함선을 탈취하십시오.

연료와 산소, 기관, 항법 장치, 화물 적재량, 승무원과 선체 손상까지 직접 관리해야 합니다.

탐사선, 화물선, 전함, 병원선, 밀수선, 유람선 등 목적에 따라 다양한 함선을 운용할 수 있습니다.

SYSTEM FILE 14

14컷｜거점 건설

아무것도 없는 땅에

당신의 거점을 세우십시오.

야영지에서 시작해 전초기지와 개척도시로 성장시키고, 전력, 산소, 식량, 방어, 창고와 생산 시설을 관리합니다.

다른 행성에는 채굴, 보급, 통신, 무역을 담당하는 보조 거점도 건설할 수 있습니다.

하지만 보급이 끊기거나 공격받으면 거점은 점령되거나 파괴될 수 있습니다.

SYSTEM FILE 15

15컷｜거주지와 생활

생존만 하는 삶에서

원하는 삶으로.

판잣집과 컨테이너 주택부터 스마트하우스, 고급 레지던스, 대저택과 궁전까지.

SP를 모아 거주지를 구매하거나 퀘스트와 세력 공헌을 통해 보상받을 수 있습니다.

집을 꾸미고, 작물을 재배하고, 동료와 가족, 반려 생명체가 머무는 생활 공간을 만드십시오.

SYSTEM FILE 16

16컷｜창업 시스템

우주에서도

먹고사는 문제는 계속됩니다.

작은 가게에서

행성 규모의 기업으로.

원하는 행성과 지역에 직접 사업장을 열고 상품, 가격, 직원, 재고, 시설과 고객을 관리할 수 있습니다.

식당, 카페, 술집, 베이커리, 의류점, 정비소, 무기점, 탐험용품점 등 다양한 업종을 운영하십시오.

위치와 계층, 치안, 세력 관계, 고객 반응에 따라 매출과 사건이 달라집니다.

SYSTEM FILE 17

17컷｜경제와 무역

행성마다

가치 있는 물건이 다릅니다.

부자가 되는 방법에도

대가가 따릅니다.

식량, 광물, 부품, 외계 유물, 희귀 생체 자원을 거래하고 도시와 행성을 오가는 무역망을 구축할 수 있습니다.

행상인으로 시작해 소형 화물선을 장만하고, 직원과 함선을 보유한 무역회사로 성장하십시오.

합법적인 계약을 선택할 수도, 암시장과 밀수에 손을 댈 수도 있습니다.

SYSTEM FILE 18

18컷｜고대 지구 요리 복원

멸망한 지구의 음식이

전설이 된 시대.

사라진 조리법과 식재료 데이터를 찾아 외계 식재료로 지구의 음식을 복원할 수 있습니다.

복원한 요리는 메뉴와 상품이 되고, 식당 운영과 농장, 탐사, 무역으로 연결됩니다.

라면 한 그릇, 떡 하나, 커피 한 잔이 누군가에게는 평생 처음 맛보는 지구의 기억이 됩니다.

SYSTEM FILE 19

19컷｜농장·채집·낚시

전투하지 않는 날도

이야기는 계속됩니다.

우주 개척자의 일상은

생각보다 바쁩니다.

기지와 온실에서 작물, 약초, 꽃과 외계 식물을 키우고 성장 환경과 토질을 관리해 수확할 수 있습니다.

바다, 강, 호수, 빙하와 외계 액체 지대에서는 지역마다 다른 생명체를 낚을 수 있습니다.

수확물은 요리, 제작, 치료와 판매에 사용됩니다.

SYSTEM FILE 20

20컷｜펫 시스템

외계 생명체도

가족이 될 수 있습니다.

돌보지 않으면

명령을 거부하거나 가출할 수도 있습니다.

야생 동물, 몬스터, 로봇과 희귀 생명체를 포획하거나 구조하고, 구매해 반려할 수 있습니다.

먹이, 치료, 훈련과 교감이 필요하며 관리 상태에 따라 호감도와 행동이 변합니다.

펫은 탐사, 전투, 채집과 생활을 보조하고 성장 단계에 따라 최대 세 차례 진화합니다.

SYSTEM FILE 21

21컷｜NPC 인연 시스템

NPC는 플레이어를 기다리며

멈춰 있지 않습니다.

관계는 선택지가 아니라

함께 쌓이는 역사입니다.

각 NPC는 고유한 직업과 목표, 성격과 이해관계를 가지며 연애, 결혼, 승진, 몰락, 배신, 사망과 세력 이동을 경험합니다.

플레이어와의 사건을 기억하고 이후 대화와 행동에 반영합니다.

동료, 친구, 연인, 경쟁자, 후원자, 고용주, 적대자까지.

SYSTEM FILE 22

22컷｜세력과 정치

하나의 우주,

서로 다른 문명과 가치관.

첨단 과학 문명 아르칸, 생태 문명 벨로라, 기계 문명 에테르, 해양 문명 네레이드, 이동 함대 노크티스와 적대 군체 제노스까지.

세력의 문화와 생태, 기술, 신앙에 따라 서로 다른 사건과 퀘스트가 발생합니다.

협력하고, 배신하고, 가입하거나 새로운 세력을 직접 만들 수도 있습니다.

SYSTEM FILE 23

23컷｜선택과 세계 변화

당신의 선택은

대화창에서 끝나지 않습니다.

모든 선택에는

다음 이야기가 존재합니다.

누구를 구했는지, 무엇을 숨겼는지, 어느 세력과 손잡았는지에 따라 다음 사건이 달라집니다.

평판이 변하고, 관계가 끊어지고, 무역로가 열리거나 전쟁이 시작될 수 있습니다.

선택하지 않은 사건도 세계 어딘가에서 계속 진행됩니다.

SYSTEM FILE 24

24컷｜마지막 통합 카피

죄수에서 개척자로.

개척자에서 탐험가로.

탐험가에서 함장으로.

함장에서 한 문명의 지배자로.

멸망 이후의 우주에서

당신은 어떤 삶을 살 것인가?

또는—

작은 집을 사고, 사랑하는 사람과 가족을 만들고, 가게와 농장을 운영하며 조용히 살아갈 수도 있습니다.

누구도 당신을 영웅으로 정하지 않습니다. 누구도 당신의 결말을 대신 선택하지 않습니다.
